# آشپزیار

برنامه موبایلی (PWA) برای محاسبه خرید و هزینه دورچین کاروان‌های عتبات عالیات. بدون سرور، روی GitHub Pages.

## ساختار

| فایل | کار |
|---|---|
| `index.html`, `js/app.js` | برنامه کاربران (مدیر کاروان، آشپز) |
| `admin.html`, `js/admin.js` | پنل مدیریت برنامه‌های غذایی |
| `js/core.js` | منطق محاسبه (مشترک) |
| `data/menus.json` | برنامه‌ها، اقلام، دستور پخت‌ها و گروه هتل‌ها |
| `data/menus.js` | نسخه پشتیبان همان فایل برای باز شدن مستقیم از روی کامپیوتر (دکمه انتشار ادمین هر دو را با هم به‌روز می‌کند) |
| `sw.js`, `manifest.webmanifest`, `icons/` | نصب روی گوشی و کار بدون اینترنت |

## راه‌اندازی روی GitHub Pages (یک بار)

1. در github.com یک مخزن جدید بسازید، مثلاً `ashpazyar` (Public).
2. همه فایل‌های این پوشه را در آن بارگذاری کنید (Add file → Upload files).
3. در مخزن: `Settings → Pages` ← در Source گزینه `Deploy from a branch` و شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.
4. بعد از یکی دو دقیقه آدرس برنامه آماده است: `https://<نام‌کاربری>.github.io/ashpazyar/`
5. پنل مدیریت: `https://<نام‌کاربری>.github.io/ashpazyar/admin.html` (این لینک را به کاربران ندهید).

## نصب برای کاربران

- **اندروید (کروم):** لینک را باز کنید ← دکمه «نصب» بالای صفحه، یا منوی ⋮ ← «نصب برنامه / افزودن به صفحه اصلی».
- **آیفون (سافاری):** دکمه اشتراک‌گذاری ⬆️ ← Add to Home Screen.

بعد از نصب، برنامه بدون اینترنت هم کار می‌کند. اطلاعات هر کاربر (قیمت‌ها، موجودی، سابقه) فقط روی گوشی خودش ذخیره می‌شود.

## به‌روزرسانی برنامه‌های غذایی

در پنل مدیریت ویرایش کنید و در زبانه «انتشار» دکمه انتشار را بزنید (یک بار باید توکن گیت‌هاب بسازید؛ راهنمایش در همان صفحه است). گوشی کاربران دفعه بعد که با اینترنت باز شود، برنامه جدید را می‌گیرد.

اگر خود کد برنامه (فایل‌های js/css/html) را تغییر دادید، عدد `VERSION` در `sw.js` را هم یکی بالا ببرید.

## قواعد محاسبه

- سرانه هر قلم = مقدار × درصد (مثلاً نوشابه ۱۱۰٪ = ۱٫۱ عدد برای هر نفر).
- اقلام عددی رو به بالا گرد می‌شوند؛ خرید به بسته کامل گرد می‌شود.
- **هزینه مصرف** = مقدار لازم × قیمت واحد (برای مقایسه با سهمیه).
- **مبلغ خرید** = تعداد بسته‌ای که باید خرید (بعد از کسر موجودی) × قیمت بسته.
- **سهمیه** = دلارِ گروه هتل × تعداد زائر × تعداد روز × نرخ دلار (وعده‌های «اضافه» مثل صبحانه سفری در تعداد روز حساب نمی‌شوند).
